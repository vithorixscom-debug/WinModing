# WinModing 0.3.1

## Highlights

- Servers: styled profile picker, faster native SLP ping, Millida logos + SLP favicons, larger curated RF/abroad list
- Auto-optimize: only exact Minecraft version matches (no Noisium/Indium from a sibling patch like 1.21.6 on 1.21.11)
- Instance icons: `iconPath` saved on create/edit; HTTPS pack icons downloaded into `icon.png`
- Modpacks: install as a new profile with the pack’s name and icon
- Browse: single pagination row (no duplicate bar when paging)
- CurseForge: newer file preferred; CDN hosts allowed for mod icons
- Skins: correct head thumbs + 3D viewer; account nick on nametag
- Catalog settings persist across relaunch
